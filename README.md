# reponomics-dashboard-dev

### This was, for period of time, the development repository for the [Reponomics Dashboard](https://github.com/reponomics/reponomics-dashboard-action) template repo.

### The project began as a single repo, which then split into two, and is now blissfully reunited once again to live in harmony as one.

### Whether you came here to reminisce about the old days, or in the hopes of discovering some skeletons in our closet, or because you clicked the wrong link somewhere, we hope that you enjoy this treasure and, more importantly, that you will remove it from your bookmarks and instead join the party over at [`reponomics/reponomics-dashboard-action`](https://github.com/reponomics/reponomics-dashboard-action).
