# Support

This repository is a published template artifact.

## Help And Questions

- Template setup/documentation/workflow-shell questions:
  - Open an issue in [`reponomics/reponomics-dashboard-dev`](https://github.com/reponomics/reponomics-dashboard-dev)
- Runtime action behavior questions:
  - Open an issue in [`reponomics/reponomics-dashboard-action`](https://github.com/reponomics/reponomics-dashboard-action)

Include:

- repository URL
- workflow run URL
- action mode (`collect`, `publish`, `rotate-key`, `incident-reset`, or `docs-sync`)
- privacy mode (`strong`, `casual`, or `plain`)
