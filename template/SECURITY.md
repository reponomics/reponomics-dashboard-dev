# Security Policy

This repository is generated from `reponomics-dashboard-dev`; security fixes should be coordinated in source repositories.

## Report A Vulnerability

- Template/workflow generation issues:
  - [`reponomics/reponomics-dashboard-dev`](https://github.com/reponomics/reponomics-dashboard-dev)
- Runtime action issues:
  - [`reponomics/reponomics-dashboard-action`](https://github.com/reponomics/reponomics-dashboard-action)

Do not publish exploit details in public issues before maintainers can triage.
