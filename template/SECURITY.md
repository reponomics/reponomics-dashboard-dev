# Security Policy

> [!WARNING]
> Pre-release placeholder.
> This template is not intended for public use.

If you discover any security or privacy vulnerabilities in the Reponomics Dashboard infrastructure, you are encouraged to open a private vulnerability report in the template [development repository](https://github.com/reponomics/reponomics-dashboard-dev), the [Dashboard Action repository](https://github.com/reponomics/reponomics-dashboard-action), or the [Reponomics Dashboard Home](https://github.com/reponomics/reponomics-dashboard-home). Any findings will be greatly appreciated, however we cannot make any assurances regarding specific response expectations at the moment, since this project is not yet ready for public use.
