# Code Of Conduct

Participation in Reponomics spaces should remain respectful, professional, and constructive.

If conduct concerns arise in this repository, report them through the source repositories:

- [`reponomics/reponomics-dashboard-dev`](https://github.com/reponomics/reponomics-dashboard-dev)
- [`reponomics/reponomics-dashboard-action`](https://github.com/reponomics/reponomics-dashboard-action)
